# FitLeague 🏆

FitLeague est une application Web qui permet à un groupe d'amis de créer des défis sportifs, de participer à des challenges et de suivre leurs performances.

## Présentation

Le but de ce projet est de faciliter l'organisation des activités sportives entre amis. Chaque utilisateur peut consulter les défis, découvrir leurs détails et suivre les résultats des participants.

## Technologies utilisées

- HTML5
- Tailwind CSS
- JavaScript ES6+
- LocalStorage
- Git & GitHub

## Fonctionnalités

- Tableau de bord avec les statistiques des défis.
- Affichage des défis sous forme de cartes.
- Consultation des détails de chaque défi.
- Affichage des participants et des classements.
- Page de création d'un défi.
- Navigation entre les différentes pages.
- Sauvegarde des données avec LocalStorage.

*Certaines fonctionnalités sont encore en cours de développement.*

## Installation

1. Cloner le projet :

```bash
git clone URL_DU_REPOSITORY
```

2. Entrer dans le dossier :

```bash
cd FitLeague
```

3. Ouvrir le fichier `index.html` dans un navigateur.
